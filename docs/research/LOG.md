# FillScore research log

Findings, decisions and numbers, by topic. **Every number comes from a phase report or a persisted run.** Phase tags are in brackets.

## A. System design (decisions worth citing)
- **Placeholder grounding.** LLMs write `{{namespace.key}}` placeholders, and only the renderer inserts numbers, using one formatter (`render.format_value`). Stray numerals lead to one regeneration, then sentence redaction, then a code-built fallback sentence. [1c–1d]
- **Claim check.** Advice terms are always flagged. Counterfactual terms ("avoidable", "saved"…) are allowed only for an action that passed verification. Causal connectives ("due to", "driven by"…) and mechanism words (manipulation, spoof, exogenous…) are strict on debate text. "Whale" is allowed only beside the rendered whale-adverse count when that count is above 0. [2a, 2c, 2c.2, 3a]
- **Counterfactual verifier.** Replays the trader's own trades under an action (maker instead of taker, excluding hours, venue shift, smaller clips). It passes only if `effect_usd > max($1, 0.5% of fees)`, plus duplicate and contradiction checks, one forced re-reason, then drop. [1c]
- **Deterministic duplicate strip.** A raw numeral equal to the adjacent placeholder's rendered value is removed before grounding, which fixed gpt-oss-20b writing "42.6% … {{key}}". [2c]
- **Eval invariants** (mutation-tested; each bad output fails only its own invariant): `rating_allowed`, `evidence_cited`, `no_flagged_terms`, `numerals_grounded` (exact match to the formatter; a random-integer probe passes only 1.5–4.5%, down from about 45% before), `findings_gated`, `packet_provenance`. [3b, 3b.2]

## B. Ablation: 9-call Council vs single call [3b.2; prompt 1.5.0; single-call prompt with no specialist wording]
- **Setup:** 3 synthetic users × 3 runs per arm; free-tier Groq/Gemini routes; the same grounding, claim check and verification pipeline for both; 103 of 110 live attempts used; no degraded runs. Results: `ml-service/evals/ablation_results.md` (regenerated byte-for-byte by `evals/ablation.py`).
- **Safety invariants (5 common):** 45/45 for both arms.
- **First-pass grounding violations, synthesis call only:** Council 4.11 per run vs single 5.67. This varies by user; the single call was better on demo-aggressive (0.67 vs 4.67).
- **Rating agreement across runs:** single 9/9 vs Council 5/9.
- **Verified findings:** 0 in both arms.
- **Cost ratio, Council/single:** calls 5.2×, input tokens 3.7×, output tokens 5.2×, wall time 6.5×. Free-tier 429 retries inflate the Council's figures.
- **[3c]** With a stronger, symmetric synthesis-level evidence rule (keys with unique values), both arms cite 0/9. Measured, not gated.
- **Reading so far:** the guardrails, not the agent count, deliver safety. The Council's edge is limited to fewer first-pass violations, at about 5× the cost.
- **Limitations:** n=3 per user; synthetic users; free models; shared verifier; no ground-truth ratings; hand-chosen required keys.

## C. Quant results
- **Equal fees:** Binance and Bybit base tiers charge 0.10%/0.10%, so a fee-only maker counterfactual is exactly $0 (`test_gate_zero_findings.py`). OKX is 0.08%/0.10%. [3a]
- **Market data choice:** data.binance.vision daily **1s klines**, which are 5–20× lighter than aggTrades (BTCUSDT: 1s klines about 2–3 MB/day, against 6–65 MB/day for aggTrades). Spot data from 2025-01-01 has microsecond timestamps. The BTCUSDT file checked was dense: 86,400 rows, every gap 1 s. [4a]
- **Markout:** `side_sign × (P(t+h) − fill)/fill × 1e4`, where positive means the price moved in the trader's favour. [4a]
  - Horizons: 1, 5, 30, 60 and 300 s.
  - P(t+h) is the close of the last 1s bar that had ended by floor(t+h), so there is no look-ahead.
  - Values staler than 5 s are null; missing values are excluded, not zeroed.
- **Spread estimators** on 1-minute bars over ±30 min, with at least 10 minute-pairs: [4a]
  - Corwin–Schultz (2012, J. Finance 67(2)) and Abdi–Ranaldo (2017, RFS 30(12));
  - the conservative (smaller) estimate is used; negatives are floored at 0;
  - biases: built for daily equities, and inflated by volatility.
- **Spread-aware maker counterfactual:** `net = N·(taker−maker) + N·min(halfSpread, 1.0 bp) − adverse`, and `effect = 0.5 × Σnet` (fill-probability haircut). Adverse selection comes from the trader's own maker-fill 60 s markouts when there are at least 10 maker fills; otherwise it falls back to their taker markouts, floored at the spread credit. [4a]
- **Demo counterfactual results** (offline, real public market data, synthetic trades): no account clears the $1 threshold. [4a]
  - demo-moderate at 0.8: +$0.155.
  - demo-multi at 0.8: +$0.415.
  - **demo-aggressive: −$0.385 and −$1.061.** Its own maker fills suffered 1.53 bps of adverse selection at 60 s, more than the spread credit, so more passive execution would not have lowered modelled cost.
- **Backfill dry-run on the demo trades:** 897/897 trades priced, 0 fetch errors, a 394 MB cache. On BNBUSDT samples, Corwin–Schultz gave 2.2–3.6 bps and Abdi–Ranaldo 2.1–3.2 bps, so half-spreads came out at 1.05–1.58 bps. These **exceed the 1.0 bp cap**, and likely overstate BNBUSDT's real quoted spread (about one tick, ~0.3 bps at $310). Bar-range estimators read high on liquid crypto; this motivates a trade-sign estimator from aggTrades. [4a follow-up, 2026-11-07]
- **Open assumptions:** the 1.0 bp half-spread cap; the 0.5 fill haircut; Bybit/OKX fills priced against Binance spot.

## E. Audit 2026-11 [audit, 2026-11]

- **2026-11-07, real spread on four real days.** Measured as the trade-sign spread from aggTrades. On every day it equals exactly one tick at both the median and p90: BTCUSDT 0.0023, ETHUSDT 0.0446, BNBUSDT 3.16, SOLUSDT 1.05 bps (full spread).
  - Corwin–Schultz / Abdi–Ranaldo on the same days: 0.70/1.22, 0.81/1.52, 3.67/3.36 and 3.78/4.39 bps.
  - The 1-min-range heuristic ×0.15: 0.58, 0.62, 1.88 and 2.18 bps.
  - Limitation: one day per symbol, Jan 2024.
