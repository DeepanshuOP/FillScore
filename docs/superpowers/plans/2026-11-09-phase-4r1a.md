# Phase 4R-1a "Measurement layer v2": Implementation Plan

> **For agentic workers:** execute task by task in this session (superpowers:executing-plans). Two briefs run this plan: **4R-1a-i = Tasks 1–6** and **4R-1a-ii = Tasks 7–11**. You never commit. Deepanshu commits from the grouped commands in each report.

- **Goal:** a tested, lineage-tracked measurement layer that computes, for any fill or order, the mid from aggressor-side public prints, effective/realized spread, price impact, E/Q, and order-level implementation shortfall with opportunity cost, using the account's real fee rates. **No scoring and no UI** (that's 4R-1b).
- **Architecture:**
  - A new `ml-service/measure/` package in three layers: `data/` (market data, cache, price step) → `benchmarks.py` (quotes, mid, VWAP/TWAP) → `metrics.py` (pure metric functions, registered).
  - `enrich_fill.py` / `orders.py` compose them, and a registry generates the methodology text.
  - The backend fetches orders and fee snapshots through the existing read-only connectors. A Mongo job calls an internal ml endpoint. Results are stored on `Trade.measurement` and `Order.measurement`, both declared in the field registry.
- **Tech stack:** Python 3.11 (pandas/pyarrow, DuckDB, pytest, Hypothesis), Express/TS (Jest/Supertest, Mongoose), MongoDB Atlas.
- **Spec:** `docs/superpowers/specs/2026-11-07-measurement-v2-design.md`, §3, §5 and §8.

## Global Constraints
- `MEASURE_VERSION = "1.0.0"`, defined once in `ml-service/config/versions.py`, and recorded on every stored measurement.
- **Benchmark prints are strictly before t:** `ts < t`, never `≤`. The quote staleness limit is `5000` ms. Horizons for realized spread and impact are `[1, 15, 60, 300]` s.
- **The mid is never imputed.** Two-sided → `quality "two_sided"`; otherwise the last print → `"last_trade"`; otherwise `None`, and that fill's spread metrics are `None`.
- **Signs:** `D = +1` for buy, `−1` for sell. All bps are `× 1e4`. Positive means a cost to the trader.
- **Identities are asserted at runtime, to `1e-9`:**
  - `effective = realized_h + impact_h`;
  - `IS_total = execution + opportunity + fees`;
  - `execution = spread_part + impact_timing`.
- **Delay is never computed;** it's always `None`, with reason `"no decision timestamp"`.
- **Every stored measurement carries `marketDataRefs`:** `[{source, dataset, symbol, date|window, sha256}]`.
- **Exchange API facts** (endpoints, fields, weights, timestamp units) come from official docs via `docs-researcher`, cited in the report.
- **No Atlas writes, no `--apply`, no live LLM calls.** Public market-data downloads are allowed in scripts and for building fixtures; **tests stay offline.**
- **Locked v1 grades** are untouched; the TS engine is not modified.
- **The field registry is updated for every new persisted field** (tests and scripts only, never imported at runtime).

## Review Focus
1. **data.binance.vision spot files from 2025-01-01 onward use microsecond timestamps** (earlier files use milliseconds). Mixing them silently shifts every benchmark by 1000×. → Task 2, `test_vision_timestamp_units_detected`.
2. **A fill whose own print is in the public data** at exactly the same millisecond must not set its own benchmark. → Task 3, `test_quote_excludes_print_at_t`.
3. **Thin markets:** no opposite-side print within 5 s gives `last_trade` quality, never a stale two-sided mid; and a crossed proxy (`ask < bid`) is never used as a mid. → Task 3.
4. **REST pagination past 1,000 aggTrades** in a busy window: no gaps and no duplicates (consecutive `a` ids). → Task 2, `test_rest_window_paginates_without_gaps`.
5. **Partially filled or cancelled orders** produce opportunity cost from ordered − filled. **Fully filled orders** produce `opportunity_bps == 0`, never `None`. **Orders without order data** (fills only) are `basis: "first_fill"` with `opportunity_bps = None`. → Task 9.

### Task 3: Benchmarks (quote, mid, interval VWAP, TWAP)

**Files:**
- Create: `ml-service/measure/benchmarks.py`, `ml-service/tests/measure/test_benchmarks.py`.

**Interfaces:**
- **Produces:**
  - `Quote(ask: float|None, bid: float|None, mid: float|None, quality: Literal["two_sided","last_trade"]|None, ask_age_ms: int|None, bid_age_ms: int|None)`.
  - `quote_at(window, t_ms, max_age_ms=5000) -> Quote`:
    - `ask` = the last buyer-initiated print (`is_buyer_maker == False`) with `ts < t`;
    - `bid` = the last seller-initiated one;
    - two-sided if both ages are ≤ `max_age_ms` and `ask ≥ bid`;
    - otherwise the last print with `ts < t` and age ≤ `max_age_ms` → `last_trade`;
    - otherwise all `None`.
  - `quoted_spread(q: Quote, tick: float) -> float|None` = `max(ask−bid, tick)` for two-sided, else `None`.
  - `interval_vwap(window, start_ms, end_ms) -> float|None` (quote-volume / volume over prints in `[start, end)`).
  - `twap(window, start_ms, end_ms, step_ms=1000) -> float|None` (mean of the last print price at each step, skipping steps with no earlier print).

**Hand fixture W** (ts ms, price, is_buyer_maker): `(1000,100.00,T) (2000,100.02,F) (2500,100.10,F) (16000,100.03,T) (16500,100.05,F)`.

### Task 4: Fill metrics with runtime identities

**Interfaces** (each registered with `@metric`):
