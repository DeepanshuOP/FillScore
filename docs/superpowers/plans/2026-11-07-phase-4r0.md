# Phase 4R-0 "Stop the bleeding": Implementation Plan

> **For agentic workers:** execute task by task in this session (superpowers:executing-plans). Steps use checkbox (`- [ ]`) syntax. **You never commit.** Each task ends by recording its file list in `.work/phase-4r0.md`. Deepanshu commits from the grouped commands in the final report.

- **Goal:** repair the 4a `spreadBps` collision, stop showing mislabelled numbers, remove the regime placeholder, hide the simulated demos, fix the guard and consolidate the roadmap, **without changing any locked grade.**
- **Architecture:**
  - A shared field registry declares every persisted Trade field's type and owner. The 4a estimator output moves to `spreadEstimates`.
  - Dashboard component cards read engine-computed component means.
  - Prompt and copy changes are covered by negative-string tests.
  - Everything that writes to Atlas is a dry-run-default script.
- **Tech stack:** Express/TS (Jest/Supertest), Next.js 16 (Vitest), FastAPI/Python 3.11 (pytest + Hypothesis), Bash guard hook.
- **Spec:** `docs/superpowers/specs/2026-11-07-measurement-v2-design.md`, §2 and §4. Read it first.

## Global Constraints
- **No locked grade changes.** `gradeInvariance.test.ts` stays green. The six stored demo audits are never rewritten by any task.
- **No Atlas writes, no `--apply`, no seed/generator/enrich/regen execution.** Reading those files is now permitted in writing (spec D1).
- No live LLM or exchange calls. Tests stay offline. Never print secrets; check env vars by key name only.
- No git commit, push, reset, stash or branch change. Write files with Write/Edit only. Never work around a guard; a block → BLOCKED with the exact message.
- TDD with hand-computed values. **Test values are ground truth: fix the code, never the test.**
- Copy rules: product rule I1 (audit the past, never advise). The existing claim/advice term tests apply to every new string.
- Field registry: read by **tests and scripts only**, never imported at service runtime (the Docker build contexts don't include `shared/`).

## Review Focus
1. **Real-user trades with `spreadBps` missing, null or NaN** (not yet enriched) still score exactly as before: the existing fallback, no throw. → Task 1, `test_scorer_handles_missing_spreadBps`.
2. **Trades with no `spreadEstimates`** (never backfilled): render, counterfactual and the markouts card degrade to "no estimate", with no KeyError and no $0 presented as a finding. → Task 1.
3. **The migration run twice** is a no-op the second time, and a dry-run never writes. → Task 2.
4. **A hidden demo reached by direct URL** (`/share/demo-bybit`, `/api/audit/...?demo=demo-okx`) returns a clean 404 `demo_unavailable`, never a 500 or the data. → Task 6.
5. **Chained shell commands that hide execution behind a read** (`cat x && npm run seed`, `grep a f; python ml-service/whale/enrich.py`) are blocked. → Task 7.
